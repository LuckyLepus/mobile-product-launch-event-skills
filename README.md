# Mobile Product Launch Event Skills / 手机产品发布会活动技能包

Three portable, bilingual `SKILL.md` files for traditional public-relations product launches. They are plain Markdown instructions, not tied to one agent, model, software vendor, brand, product, or client. Copy a skill folder into an agent's skills directory, or provide its `SKILL.md` as task instructions. Use only the skill relevant to the current task.

三份可移植的中英双语 `SKILL.md`，适用于传统公关形式的手机产品发布会。文件是普通 Markdown 指令，不依赖特定智能体、模型、软件厂商、品牌、产品或客户。可将文件夹放入智能体的技能目录，也可把对应 `SKILL.md` 作为任务说明提供。每次只选当前任务需要的技能。

| Skill / 技能 | Applications / 适用工作 | Deliverables / 交付物 |
| --- | --- | --- |
| [`editable-presentation-writing`](editable-presentation-writing/SKILL.md) | Turn a brief, draft, table, or visual reference into an editable presentation; revise individual pages; preserve a supplied layout; prepare review versions. / 将需求、草稿、表格或视觉参考转为可编辑演示文稿；逐页改稿；沿用指定版式；输出评审版本。 | Editable slide file, page preview, concise change notes. / 可编辑文件、页面预览、简要改动说明。 |

## Privacy and reuse / 隐私与复用

The package deliberately contains no source brief, artwork, screenshots, quotation, name, slogan, metric, proprietary claim, or project path. Before publishing any adaptation, inspect all files and generated assets for information that a client or employer has not approved for disclosure. Replace specifics with neutral placeholders or remove them entirely. A clean skill is not authorization to publish project material.

本包不包含原始需求、画面、截图、引文、名称、口号、参数、专有卖点或项目路径。发布任何改编版本前，应检查全部文件与生成素材，移除未经客户或雇主允许公开的信息。可用中性占位符替代，也可直接删除。技能包本身可公开，不代表项目素材获得公开授权。
