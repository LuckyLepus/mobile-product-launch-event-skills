# Stage and exhibition white models / 舞台与展区白模

Use this skill for early spatial communication: stage structure, product display, exhibition circulation, top views, elevations, and clay renders. A white model explains geometry and visitor experience; it is not a construction drawing or a final lighting specification.

用于前期空间沟通：舞台结构、产品陈列、展区动线、顶视图、立面和白模效果图。白模用于解释几何关系和观众体验，不等同于施工图或最终灯光规格。

## Workflow / 工作方法

1. **Read the spatial brief.** Identify entry and exit, viewing direction, screen and display positions, presenter or visitor scale, sightlines, circulation width, and any fixed venue constraints. Separate confirmed dimensions from concept assumptions.
   **读取空间条件。**明确出入口、观看方向、屏幕与陈列位置、人物尺度、视线、通道宽度和场地固定条件；区分已确认尺寸与概念假设。
2. **Start with relationships, then appearance.** For an exhibition, map the route from entrance to core display and onward; for a stage, map audience, speaker, screen, overhead structure, and access. A top view should clarify movement before perspective views add atmosphere.
   **先定关系，再定外观。**展区先梳理入口、核心装置和后续区域的动线；舞台先梳理观众、讲者、屏幕、顶部结构与上下场路径。顶视图先说明动线，再用透视图表达氛围。
3. **Lock a base model.** Use one consistent footprint and coordinate system across top, front, and oblique views. Preserve fixed geometry when revising a detail. If the user supplies a sketch or model, keep its major proportions unless asked to change them.
   **锁定基础模型。**顶视、正视和斜视共用同一空间轮廓与坐标关系。修改局部时保留固定几何。若用户提供手绘或模型，除非提出变更，否则保留主要比例。
4. **Render a clean clay view.** Use neutral materials, controlled light, restrained joints and seams, believable contact shadows, and a human scale reference. Avoid stray fragments, accidental texture, excessive bloom, misleading floating objects, and decorative effects that obscure the structure.
   **输出干净白模。**使用中性材质、受控光线、克制的拼缝、可信的接触阴影与人物比例参照。避免碎片、意外纹理、过曝光晕、无依据悬浮物，以及遮挡结构的装饰特效。
5. **Show functional consistency.** A screen should have a plausible support relationship; overhead features should read as suspended or supported; a display plinth should connect to the floor. Check that openings, paths, stairs, and viewing angles remain usable.
   **检查使用关系。**屏幕应有合理支撑，顶部装置应看得出吊挂或支承方式，展台应落地。检查开口、通道、台阶及观众视角是否可用。
6. **Revise locally and inspect all affected views.** When replacing one element, update every image where it appears. Compare before and after at the same camera angle. Save a new version and keep the previous design recoverable.
   **局部修改并检查所有相关视角。**替换一个元素时，同步修改出现该元素的全部视角。使用相同机位对照新旧图。另存版本，保留旧方案可回溯。

## Output notes / 交付说明

- Label views and state what each one proves: plan, entry experience, frontal view, or detail. / 标明每张图的用途：平面、入场视角、正视或细节。
- State which dimensions and structures are conceptual, and which require a production designer or venue engineer to verify. / 说明哪些尺寸与结构仍是概念，哪些需要搭建团队或场地方复核。
- If images are generated rather than derived from a true 3D model, describe them as visual concepts; do not claim geometric precision that was not checked. / 若图像由生成工具制作而非真实三维模型导出，应标明概念效果，不宣称未经核验的几何精度。
- Remove or replace confidential logos, identifiable product geometry, venue drawings, and source artwork before any public reuse. / 对外复用前，移除或替换保密标识、可识别产品造型、场地图纸和原始视觉素材。
